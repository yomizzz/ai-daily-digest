warelay 1.3.0

🆕 新增功能

  • **可插拔代理架构**：支持 Claude、Pi、Codex、Opencode 等多种代理，通过 `inbound.reply.agent` 配置选择 CLI 和解析器
  • **代理安全停止词**：入站消息为 `stop`、`esc`、`abort`、`wait` 或 `exit` 时立即终止代理并提醒用户
  • **IPC 服务器通信**：通过 Unix 套接字实现 `warelay send`/`warelay heartbeat` 与运行中的 relay 共享连接
  • **批量消息处理**：多条 WhatsApp 消息合并为一批并附时间戳发送给代理，保持顺序和上下文
  • **IPC 发送后自动显示输入指示器**：通过 IPC 发送消息后自动显示"正在输入"状态
  • **WhatsApp 会话卡死自动恢复**：30分钟无消息活动时自动重启连接，修复 Bad MAC 解密错误导致的卡死
  • **同一手机号模式**：支持在相同号码上自发自收消息，可配置标记前缀（默认 `[same-phone]`）
  • **回声检测**：同一手机号模式下追踪最近发送的消息，防止无限循环自动回复

🐛 Bug 修复

  • **空结果字段处理**：Claude CLI 返回 `result: ""` 时正确处理为空输出，而非发送原始 JSON
  • **心跳回复响应前缀**：修复 `responsePrefix`（如 🦞）在心跳提醒消息中未应用的问题
  • **用户可见错误消息**：命令执行失败（非零退出、被终止、异常）现在返回用户友好的错误提示
  • **测试会话隔离**：修复测试文件污染生产 `sessions.json` 的问题
  • **信号会话损坏预防**：通过 IPC 机制防止 `warelay send` 与 relay 同时连接导致会话状态损坏
  • **Web 发送媒体类型识别**：修复所有媒体都错误发送为图片的问题，正确区分音频/视频/图片/文档
