Hermes Agent v0.22.3

hermes hermes-agent · 2026-10-21

← 返回日报
  • v0.22.3 是补丁版本，集中合并自 v0.22.2 以来的约 620 个 PR，涵盖 CLI、安装器、Microsoft Store 应用、Docker 与 Hermes Cloud。
  • 本次更新包含 2,911 个非合并提交，共修改 4,206 个文件；约 620 个 PR 合并，并关闭 326 个 Issue。
  • MCP 进度通知得到增强，可将工具执行进度以实时流式形式展示。
  • 经典 CLI 界面完成刷新，新增字形记录区、输入框下方状态栏及双行标题栏。
  • 插件支持声明 OAuth 客户端，由 Hermes 统一完成登录、令牌刷新与生命周期管理。
  • 新增 `hermes plugins update`，可批量获取可用插件更新；Desktop 端也为 Git 安装的插件提供“更新”按钮。
  • Desktop 新增队列提示词编辑与引导式操作，支持在任务执行前调整待处理指令。
  • Desktop 提供引导式子代理模型与提供商选择器，便于按任务配置执行环境。
  • CLI 与 TUI 的 `/loop` 命令新增实时倒计时行。
  • Telegram 私信支持可选的话题转移功能。
  • 新增 `post_compaction` 插件钩子，可在上下文压缩后执行自定义逻辑。
  • 新增能力目录，用于集中展示和查询系统支持的功能。
  • Microsoft Store 版本现可在新 Release 发布时自动上线。
  • 磁盘空间不足时将一次性提示用户，并默认保持会话自动清理为选择性启用。
  • 本地运行时新增 Nemotron 3.5 Bolt 与单槽位 DFlash 草稿支持。
  • 插件目录新增数十个条目，进一步扩充可用插件生态。
  • Microsoft Store 应用通过商店更新；已通过 `.exe` 或 `.dmg` 安装的 Desktop 应用将在下一次捆绑发布时更新。
  • CLI 可通过 `hermes update` 或重新运行安装器命令更新；Docker 与 Hermes Cloud 可使用 `nousresearch/hermes-agent:stable` 或 `:latest` 镜像。
  • 本版本的完整整理版发布说明及完整贡献者名单将在 v0.23.0 中统一提供。
