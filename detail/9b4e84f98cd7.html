Hermes Agent v0.22.5

hermes hermes-agent · 2026-10-23

← 返回日报
  • v0.22.5 为补丁版本，汇总自 v0.22.4 以来的约 81 个 PR，包含 231 个非合并提交，改动 804 个文件，并关闭 30 个问题。
  • 重构 Nous 登录流程：统一采用设备登录，支持免费访客账号交接、登录身份展示及连接器直接登录。
  • 改进 `hermes update`：稳定版本不可用时不再错误提供升级，并可修复损坏的 `.git` 仓库、恢复暂停的网关进程。
  • 新增按时间窗口计费的套餐支持，包括套餐用量指示、限额卡片及模型切换后的额度恢复。
  • 支持可插拔的子代理委派后端，可按模型映射或配置档案路由子代理，并允许按会话切换。
  • 插件新增斜杠命令交互选项，并支持一键安装插件及展示套餐等级徽章。
  • 新增 `hermes import-agent`，可检测并导入其他代理生态的数据；同时提供 OpenClaw 迁移能力。
  • 新增 `hermes mcp serve`，并提供实验性的 Webhook 模式 MCP 事件客户端。
  • 将 Singularity 后端从核心移至插件，核心模块更易维护和扩展。
  • 桌面端支持从侧边栏拖拽固定应用，群聊界面重新显示当前正在工作的机器人。
  • Windows 执行 Python 版本重定向更新后，不再卡在旧启动器；Windows 更新流程也得到改进。
  • 修复聊天工作目录丢失时提示不清晰的问题。
  • 修复 Claude DirectSDK 长回答可能因停滞计时器而被提前截断的问题。
  • Electron 升级至 44，Pillow 升级至 13，并批量更新依赖以修复安全问题。
  • 完整、分类整理的发布说明将在 v0.23.0 提供；本版本没有跳过任何变更，仅暂不逐项记录。
  • Microsoft Store 应用通过商店更新；Docker 与 Hermes Cloud 使用 `nousresearch/hermes-agent:stable` 或 `:latest` 镜像。
  • 通过安装器安装的 CLI 和桌面版可使用 `hermes update` 更新；桌面安装版（`.exe`/`.dmg`）本次无改动，将随下个捆绑版本升级。
