Hermes Agent v0.23.5

hermes hermes-agent · 2026-11-28

← 返回日报
  • v0.23.5 为补丁版本，自 v0.23.4 起累计合并 338 个 PR，包含 1,262 个非合并提交，修改 1,146 个文件，并关闭 92 个问题。
  • 本次版本面向 GitHub CLI 与安装器、Microsoft Store 应用、Docker 镜像及 Hermes Cloud 同步发布稳定更新。
  • CLI 和 TUI 新增对 OSC 7577 程序恢复协议的支持，可用于恢复外部程序或会话。
  • 网关在所有路由中后台压缩空闲聊天记录，降低长期空闲会话对上下文的占用。
  • `read_file` 支持从负偏移位置跟踪文件末尾输出，并支持列出目录内容；`search_files` 可明确提示内容搜索是否已找到全部结果。
  • Desktop、Docker 和 CLI 启动本地网关前，会以受限方式预检默认插件，提前发现配置或加载问题。
  • 插件 OAuth 配置支持固定重定向 URI，提升不同运行环境下的授权稳定性。
  • Solstice 提供商迁移至无状态的 Interactions API，简化请求处理并减少服务端状态依赖。
  • 插件 API 新增会话来源、会话创建方式、Cron 调度及网关静默辅助等能力，方便扩展自动化与生命周期管理。
  • 仪表板新增“your dashboard is moving”迁移提示；会话和插件选择器现可正常识别原始方向键输入。
  • 修复插件工作配置在用户配置重命名、移动或删除后绑定错误的问题，确保插件始终关联正确的用户配置。
  • CLI 可通过 `hermes update` 或重新运行安装器命令升级；Docker 和 Hermes Cloud 可使用 `nousresearch/hermes-agent:stable` 或 `:latest` 镜像。
  • Microsoft Store 应用通过商店自动更新；桌面安装版（`.exe` / `.dmg`）本次无需操作，将随下个捆绑版本升级。
  • 本窗口的完整精选说明与全部贡献者名单将在 v0.24.0 发布，本次变更没有被省略。
