Hermes Agent v0.21.6

hermes hermes-agent · 2026-10-08

← 返回日报
  • 首个基于稳定版发布管道构建的版本，包含经过测试的 Docker 镜像和发布标签
  • 自 v0.21.5 以来的更新窗口：8,867 个非合并提交、8,342 个变更文件、2,106 个合并 PR、3,027 个关闭的 issue
  • CLI、TUI 和桌面端新增实时语音转录功能（`stt.streaming`）
  • 语音对话路由至独立辅助模型（`auxiliary.voice_chat`），推理默认关闭
  • 第三方插件在独立插件主机中隔离运行（`plugins.isolation: host`），并在设置页面新增插件管理入口
  • 桌面端模型选择器支持收藏和固定模型置顶显示
  • 订阅使用量在达到限制前显示提醒芯片，受速率限制的提供商显示原因和恢复时间
  • 本地模型支持新增 `hermes model` 命令及 Linux x64/arm64 的 llama.cpp CUDA 加速
  • 支持可插拔、分层的语言包，覆盖核心程序、桌面端和 TUI
  • 新增摘要优先的 `hermes status` 命令（`--short`、`--full`）
  • 审查面板新增 diff 范围选择器（未提交/分支/上一轮），并支持跟随对话保持常亮
  • cron、doctor 和 home-channel 在 cron 存储不可写时发出警告
  • 凭证上传增加审批标志，终端命令支持不可见 Unicode 检测
  • Discord 集成新增机器人令牌验证和邀请链接输出
  • 模型目录新增 GPT-6.1 Sol、Claude Sonnet 5.5 和 Haiku 5.5
  • 数十个新社区插件
  • Docker 和 Hermes Cloud 更新至 stable/latest 标签，桌面端和 Termux 本次不更新
  • 安全修复：修复仪表盘认证中 X-Forwarded-For 伪造、无限写审计日志、请求体无大小限制等漏洞
